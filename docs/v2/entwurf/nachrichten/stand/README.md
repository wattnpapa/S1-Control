# Nachrichten – Stand der laufenden Anwendung

Aufgenommen am 17.11.2026 in der Web-Schale (`node apps/desktop/out/web.mjs`, Chromium über Playwright),
Fassung `be6f9b9`, Viewport 1320 × 860, deviceScaleFactor 2 (2640 × 1720 Pixel).
Durchlauf: Einsatz „Übung Hochwasser Oldenburg“ mit Parameter „LdF als eigene Station“ und Schwelle der FmZ 1 Minute,
fünf Browser-Kontexte als Stellen S4 (Hz. Ru), FmZ (Hz. Ha), LdF (Hz. Sch), Sichter (Hz. Si) und S2 (Hz. Mü), dazu für die
Doppelsichtung ein zweiter Sichter (Hz. Zw). Das Bild posteingang-leer stammt aus einem zweiten, leeren Einsatz („Übung Leerlauf“),
weil der Einsatz des Durchlaufs beim Aufnehmen schon Nachrichten trug.
